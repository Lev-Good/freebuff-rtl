# Freebuff Desktop — עברית, RTL ומרכז כלים מאוחד (All-in-One)

**גרסה נוכחית: 1.7.0** — שדרוג מקיף לחבילה מאוחדת ושלמה:
* **כפתור כלים מאוחד בתוכנה (`⚙️ כלים`)**: כפתור צף הניתן לגרירה לכל מקום במסך עם תפריט הגדרות מהיר לשליטה בכל רכיב בנפרד.
* **תרגום ממשק מלא לעברית**: מנוע תרגום מובנה (כולל מילון מונחי ליבה ואינטגרציית תרגום חכמה ובטוחה).
* **חסימת פרסומות בצ'אט**: ניטרול כל סוגי הפרסומות וההצעות (Partner Ads, Intermissions, Prompts).
* **שליטה על עדכונים אוטומטיים**: אפשרות לחסום או לאפשר עדכוני תוכנה ישירות מתוך התוכנה.
* **מתקין ראשי חדש (`Setup-Freebuff-Tools.bat`)**: תפריט התקנה נוח עם אפשרות להתקנה מלאה בלחיצה אחת או התקנה מותאמת אישית של רכיבים נבחרים.
* כולל את כל שיפורי האמינות והיציבות מגרסאות 1.5.x-1.6.x (שומר קבוע ב-`%LOCALAPPDATA%`, משימות מתוזמנות, משגר VBS נסתר ועמידות בפני עדכונים).

| | המתקין הראשי (`Setup-Freebuff-Tools.bat`) | הקבועה (`install-permanent.bat`) | הפשוטה (`apply-rtl.bat`) |
|---|---|---|---|

## הדרך הקבועה — התקנה אחת, שורדת עדכונים לנצח

עדכון של Freebuff מחליף את קבצי התצוגה ומוחק את תיקון ה-RTL. כדי שלא
תצטרכו להריץ שוב כל פעם, מתקינים פעם אחת שומר קטן שרץ ברקע:

1. לוחצים פעמיים על **`install-permanent.bat`**.
2. זהו — זהו. הסקריפט מתקין את התיקון עכשיו, ורושם התחלה אוטומטית
   (מפתח Run של המשתמש — בלי הרשאות מנהל, בלי חלון שנפתח).

מעכשיו, בכל כניסה ל-Windows השומר מתחיל מתוך תיקייה יציבה באנגלית, ובכל פעם
שעדכון Freebuff מחליף את קובצי ה-UI — השומר מזהה את זה תוך שניות ומחזיר
את ה-RTL **ואת מתג הכיוון** לבד. אתם לא צריכים לעשות כלום. יומן פעילות נשמר
ב-`%LOCALAPPDATA%\freebuff-rtl\autopatch.log`.

החל מגרסה 1.5.0 נוספה גם שכבת הגנה שנייה: שתי משימות מתוזמנות של
Windows (נרשמות בלי הרשאות מנהל, דרך ה-COM API של Task Scheduler).
הראשונה מריצה את השומר בכל כניסה ל-Windows, והשנייה — **שומר-משנה** —
בודקת כל 5 דקות אם השומר עדיין חי, ומריצה אותו מחדש אם הוא מת. כך שגם
אם השומר נסגר או נפל (או שהמחשב נשאר דולק ימים בלי כניסה מחדש) — הוא
חוזר תוך דקות, והתיקון אף פעם לא נשאר חסר.

החל מגרסה 1.5.1 המשימות מפעילות את הסקריפט דרך משגר VBS נסתר
(`freebuff-rtl-hidden.vbs` + `wscript.exe`) במקום ישירות מ-Task
Scheduler — זה מונע את ההבהוב הקצר של חלון שורת הפקודה שהופיע בכל
בדיקה תקופתית של השומר-המשנה. מפתח ה-Run נשאר ישיר ומוסתר כביטחון
כפול.

**להפסיק את זה:** לוחצים פעמיים על `remove-permanent.bat` (התיקון עצמו
נשאר — אם רוצים גם לחזור ל-LTR, מריצים גם `remove-rtl.bat`).

## עדכון אוטומטי של הסקריפט — ההודעה בתוך Freebuff

הסקריפט יודע לבד אם יצאה גרסה חדשה שלו, ומודיע על זה בתוך Freebuff:

1. השומר הקבוע (`freebuff-rtl-autopatch.ps1`) בודק כל כמה שעות ב-GitHub
   אם יצאה גרסה חדשה. אם כן — הוא מוריד אותה, מחליף את קבצי הסקריפט
   הישנים (וגם מוחק קבצים שנשארו מגרסאות קודמות), ומתקין אותה.
2. במקביל, בתוך Freebuff מוקפץ כרטיס קטן ליד מתג הכיוון: **"עדכון זמין
   לסקריפט RTL"** עם שלושה כפתורים:
   - **עדכן והפעל מחדש** — מוודא שהגרסה החדשה הותקנה, סוגר את Freebuff
     ומפעיל אותו מחדש עם הסקריפט החדש. קבצי הגרסה הישנה נמחקים
     אוטומטית.
   - **הורדה ידנית** — פותח את דף המהדורה ב-GitHub (למי שלא התקין את
     הדרך הקבועה).
   - **סגור** — מסתיר את ההודעה (היא תחזור בעדינות אחרי שבוע, או כשיצא
     גרסה חדשה עוד יותר).

**חשוב:** העדכון האוטומטי המלא (הורדה + התקנה + סגירה + הפעלה מחדש)
עובד בדרך הקבועה (`install-permanent.bat`) — כי השומר הוא היחיד שיכול
לסגור את Freebuff ולהפעיל אותו מחדש. בדרך הפשוטה (`apply-rtl.bat`) תופיע
גם ההודעה, אבל רק עם קישור להורדה ידנית.

## מצב בהיר/כהה — מובנה ב-Freebuff עכשיו

גרסאות קודמות של הסקריפט כללו מתג שמש/ירח שהחליף בין תצוגה כהה לבהירה
ונשמר בין הפעלות. מאז ש-Freebuff הוסיף מצב בהיר/כהה רשמי, המתג הזה הוסר
מהסקריפט — אין צורך בפתרון ביתי. מי שהתקין גרסה קודמת: הרצה חוזרת של
`apply-rtl.bat` (או עדכון של השומר הקבוע) מנקה את שאריות המתג הישן
מהקבצים.

## הדרך הפשוטה — התקנה בהקלקה אחת

צריך רק 3 קבצים מאותה תיקייה:

```
apply-rtl.bat              ← זה שמקלקים עליו
freebuff-rtl.css           ← הגליון עצמו (חייב להיות ליד ה-bat)
freebuff-rtl-dragfix.js    ← תיקון כיוון הגרירה (חייב להיות ליד ה-bat)
```

עושים בדיוק כך:

1. **סוגרים את Freebuff** לגמרי (כולל חלונות צ'אט פתוחים).
2. לוחצים פעמיים על `apply-rtl.bat`.
3. פותחים את Freebuff — הצ'אט עכשיו מימין לשמאל. ✓

הסקריפט עושה שלושה דברים:
1. מוסיף את גליון ה-CSS בסוף קובץ העיצוב של האפליקציה.
2. מוסיף `dir="rtl"` לתג ה-html — הסימון הזה הוא שמפעיל את כל הגליון
   (בלעדיו ה-CSS לא היה נכנס לפעולה).
3. מזריק ל-`index.html` סקריפט קטן שמתקן את כיוון הגרירה של ידית
   גודל החלונית — האפליקציה בנויה על כיוון גרירה של LTR, וב-RTL
   צריך למשוך לכיוון ההפוך.

הוא מוצא לבד את תיקיית ההתקנה, עוצר אם כבר הותקן, ושומר גיבוי של קובץ
ה-CSS המקורי (שם הקובץ + `.pre-rtl.bak`).

**אחרי שעדכון של Freebuff יורד** — העדכון מחליף את קבצי התצוגה והתצוגה
חוזרת ל-LTR. פשוט לוחצים שוב על `apply-rtl.bat` וזה חוזר. (כל ריצה מחדש
לוקחת שנייה ואין סיכון להכפלה.)

### להסיר

לוחצים פעמיים על `remove-rtl.bat` (אותו תיקייה). זה מסיר את ה-CSS ואת
הסימון `dir="rtl"` — ומחזיר את הקבצים בדיוק למצבם המקורי.

## מה להגיד לחברים (העתיקו והדביקו)

> **רוצה תצוגה מימין לשמאל ב-Freebuff?**
>
> זה פתרון ביתי קטן שהופך את הצ'אט ל-RTL. קובצי ההתקנה כאן:
> [צרפו: `apply-rtl.bat` + `freebuff-rtl.css` + `freebuff-rtl-dragfix.js`]
>
> איך מתקינים (שתי דקות):
> 1. סוגרים את Freebuff לגמרי.
> 2. מורידים את שלושת הקבצים לאותה תיקייה.
> 3. לוחצים פעמיים על `apply-rtl.bat`.
> 4. פותחים את Freebuff — וזהו, התצוגה מימין לשמאל.

> גררו את תיקיית `ui\assets` של Freebuff אל חלון הפקודה — או כתבו לי ואעזור.
>
> אחרי שעדכון Freebuff יורד, פשוט לוחצים על `apply-rtl.bat` שוב.
> אם רוצים לחזור ל-LTR — לוחצים על `remove-rtl.bat`.

## ניסוי מהיר בלי להתקין (חד-פעמי)

רוצים לראות איך זה נראה לפני שמתקינים?

1. ב-Freebuff לוחצים `Ctrl+Shift+I` (ב-macOS: `Cmd+Option+I`) — נפתח DevTools.
2. מדביקים ב-Console את כל התוכן של `rtl/freebuff-rtl.js` ולוחצים Enter.
3. התצוגה מתהפכת מיד. זה נמחק אחרי רענון או סגירת האפליקציה.

## הדרך המתקדמת — Launcher ששורד עדכונים (Windows)

לא נוגע בקבצי האפליקציה בכלל — מזריק את התצוגה בזמן ריצה דרך Chrome
DevTools Protocol, כך שעדכוני גרסה לא מפריעים.

**חשוב:** Freebuff מאפשר מופע אחד. סוגרים אותו קודם, ואז:

```powershell
powershell -ExecutionPolicy Bypass -File rtl\freebuff-rtl.ps1
```

הסקריפט פותח את Freebuff, מזריק RTL לכל חלון (כולל תיקון כיוון הגרירה
שנכלל ב-`freebuff-rtl.js`), ונשאר פתוח ברקע (אפשר למזער). סגירת החלון /
`Ctrl+C` עוצרת את ההזרקה — Freebuff ממשיך כרגיל. מכאן ואילך תמיד פותחים
את Freebuff דרך הסקריפט.

## שאלות נפוצות

**זה בטוח?** כן — ה-CSS רק משנה את התצוגה (יישור, כיוונים). הוא לא נוגע
בקבצים, בפרויקטים או בהודעות שלכם, וכל כלל בו מופעל רק כשהמאפיין
`dir="rtl"` קיים על תג ה-html — כך שאין סיכון לתצוגה רגילה. הסקריפט
מגדיר את המאפיין הזה בעצמו, וסקריפט הגרירה נוגע רק באירועי עכבר שמתחילים
על ידית הגודל של החלונית — כל שאר פעולות העכבר לא מושפעות. הכל ניתן
להסרה מלאה עם `remove-rtl.bat`, ולפני כל שינוי נשמר גיבוי.

**מה אם Freebuff מותקן במקום אחר?** מריצים עם הנתיב:
`apply-rtl.bat "C:\path\to\resources\orchestrator\ui\assets"`

**למה אחרי עדכון זה חוזר ל-LTR?** כי עדכון מחליף את קבצי התצוגה. אם
התקנתם את הדרך הקבועה (`install-permanent.bat`) — לא צריך לעשות כלום,
השומר מתקן לבד תוך שניות. אחרת לוחצים שוב על `apply-rtl.bat` — שנייה
וזה חוזר.

**מה בדיוק רץ ברקע?** `freebuff-rtl-autopatch.ps1` — סקריפט קטן שבודק
כל כמה שניות אם הקבצים של Freebuff עוד מכילים את התיקון. כשעדכון מחליף
אותם, הוא מריץ את `freebuff-rtl-patch.ps1` שמתקין מחדש. הוא רשום במפתח
ההפעלה של המשתמש (`HKCU\...\Run`) **ובשתי משימות מתוזמנות של Windows**:
משימת כניסה שמתחילה אותו בכל כניסה ל-Windows, ושומר-משנה שבודק כל 5
דקות אם הוא חי ומריצה אותו מחדש אם לא — בלי הרשאות מנהל ובלי חלון שנפתח.

**מה קרה למתג הבהיר/כהה?** הוא הוסר — Freebuff הוסיף מצב בהיר/כהה
רשמי, אז אין צורך בפתרון ביתי. אם גרסה ישנה הותקנה אצלכם, הרצה של
`apply-rtl.bat` או של השומר הקבוע מנקה את שאריותיה.
